# TikBVW

Собствена алтернатива на **TikFinity** / **BetterTok** за TikTok LIVE —
собствен сървър, собствен overlay за OBS, и говорител (TTS) задвижван от
**Piper** с българския глас `bg_BG-dimitar-medium`, вместо облачни TTS услуги
на трети страни.

## Какво прави

- Свързва се към произволен активен TikTok LIVE стрийм (по потребителско
  име) чрез [`tiktok-live-connector`](https://github.com/zerodytrash/TikTok-Live-Connector) —
  без нужда от парола или API ключ за самото гледане на чата.
- Приема на живо: чат съобщения, подаръци (с обработка на streak-ове),
  следвания, споделяния, лайкове, брой зрители.
- Озвучава събитията с локален TTS (Piper) — говори на български, изцяло
  локално, без да изпраща текст към трети страни.
- Контролна зала (dashboard) в тъмна "broadcast console" естетика: статус
  на връзката, лента на събитията на живо, индикатор кога говорителят е
  активен, всички TTS настройки на едно място.
- Прозрачен **overlay.html** за OBS / TikTok Live Studio Browser Source —
  анимирани картички за подаръци/следвания/чат плюс аудио на говорителя.
- Настройките (кои събития да се четат, скорост на говор, минимален брой
  монети за подарък, черен списък с думи) се пазят между рестарти в
  `data/config.json`.

## Структура на проекта

```
TikBVW/
  server.js              главен Express + Socket.IO сървър
  src/
    tiktokManager.js      връзка към TikTok LIVE, нормализирани събития
    ttsEngine.js           опашка + извикване на Piper бинарника
    configManager.js       зареждане/запазване на настройки (JSON)
  public/
    index.html             контролна зала (dashboard)
    overlay.html            прозрачен overlay за OBS
    css/style.css
    js/dashboard.js
    js/overlay.js
  piper/                   Piper бинарник + библиотеки (включени за Linux x86_64)
  voices/                  тук отиват .onnx / .onnx.json файловете на гласа
  data/config.json         генерира се автоматично при първо стартиране
```

## Инсталация

### 1. Инсталирай Node.js зависимостите

```bash
npm install
```

### 2. Осигури Piper бинарника

За Linux x86_64 бинарникът вече е включен в `piper/piper` заедно с нужните
библиотеки — няма нужда от нищо допълнително.

Ако пускаш на Windows или macOS, свали съответния архив от
[Piper Releases](https://github.com/rhasspy/piper/releases) и разархивирай
съдържанието му в папка `piper/` (пътят до изпълнимия файл трябва да е
`piper/piper` на Linux/macOS или `piper/piper.exe` на Windows). Алтернативно
задай променлива на средата `PIPER_PATH` към друго място.

### 3. Добави гласовите файлове

Постави в папка `voices/`:

- `bg_BG-dimitar-medium.onnx`
- `bg_BG-dimitar-medium.onnx.json`

(виж `voices/README.md` за откъде да ги свалиш).

### 4. Стартирай

```bash
npm start
```

Конзолата ще покаже дали Piper и гласът са разпознати правилно. После:

- Контролна зала: **http://localhost:3000**
- Overlay линк за OBS: **http://localhost:3000/overlay.html**

## Използване

1. В контролната зала въведи TikTok потребителското име на активен
   стрийм (само името, без `@` и без пълния линк) и натисни **„Свържи се"**.
2. В OBS / TikTok Live Studio добави **Browser Source** с адреса на
   overlay-а по-горе и постави прозрачен фон.
3. Настрой кои събития да се озвучават, скоростта на говор, минималния
   брой монети за подарък, черен списък с думи — всичко от десния панел
   на dashboard-а. Настройките се запазват автоматично.
4. Бутон **„Изговори текста"** пуска тестова фраза през говорителя, за да
   провериш, че всичко работи, без да чакаш реален зрител.

## Технически бележки

- Библиотеката `tiktok-live-connector` е неофициална (reverse-engineered) —
  TikTok може да променя протокола си без предупреждение. Ако връзката
  започне да failва масово, следи за нова версия на пакета.
- За по-стабилно подписване на заявките (особено при чести reconnect-и)
  може да се използва Euler Stream API ключ — виж коментара в
  `src/tiktokManager.js` (`signApiKey`).
- TTS аудиото се генерира като WAV и се праща base64-кодирано през
  Socket.IO към всеки свързан клиент (dashboard + overlay), които го
  възпроизвеждат сами — така сървърът може да работи и без звукова карта
  (напр. на VPS).
- `data/config.json` не е под git контрол по подразбиране — всяка
  инсталация пази собствени настройки.

## Възможни разширения

- Chat-bot команди (напр. `!song`, `!social`) — лесно се добавят в
  `tiktokManager.js` -> `WebcastEvent.CHAT` слушателя.
- Система с точки/канали за зрителите (channel points).
- Звукови ефекти при конкретни подаръци (отделно от TTS).
- Многоезичен TTS — просто добави други гласове в `voices/` и превключвай
  `tts.voice` в настройките.
