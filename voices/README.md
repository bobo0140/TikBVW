# Гласови модели за Piper TTS

Постави тук двата файла на българския глас:

- `bg_BG-dimitar-medium.onnx`
- `bg_BG-dimitar-medium.onnx.json`

Може да ги свалиш от официалната колекция гласове на Piper (Hugging Face,
`rhasspy/piper-voices`, папка `bg/bg_BG/dimitar/medium/`).

След като файловете са тук, рестартирай сървъра (`npm start`) — при
стартиране конзолата ще покаже дали гласът е разпознат правилно.
